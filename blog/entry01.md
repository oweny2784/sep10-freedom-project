# Entry 1: Deciding the topic
##### 10/20/26

### Topic choice
I've decided my topic should be visual art and drawing so far. This is because I really want to be able to draw better, since it feels like I can only draw the way a toddler could draw, but a bit better. I've seen some impressive stuff that others around me could draw, and I feel like mine is not as good.

### Sites
The sites that I will use include [smarthistory.org](https://smarthistory.org/what-is-art-history/) for the history of art, and [MoMA.org](https://www.moma.org/collection/terms/modern-art/technology) for current technology in art

### Skills
